# Devume Client 2

개발자를 위한 포트폴리오 플랫폼 - Devume 클라이언트 (컨셉 버전 2)

## 프로젝트 소개

Devume는 개발자들이 자신의 포트폴리오를 쉽게 제작하고 공유할 수 있는 플랫폼입니다. 이 레포지토리는 Devume의 소개용 공식 홈페이지의 두 번째 디자인 컨셉을 위한 프로젝트입니다.

## 기술 스택

- **프레임워크**: Next.js
- **언어**: TypeScript
- **스타일링**: TailwindCSS
- **애니메이션**: Framer Motion
- **테마**: next-themes (다크/라이트 모드)
- **통신**: gRPC

## 주요 특징

1. 일본 애니메이션 스타일의 디자인 컨셉
2. 화려한 애니메이션 및 인터랙션
3. 다크/라이트 테마 지원
4. gRPC 기반의 서버 통신
5. 포트폴리오 프리뷰 및 쇼케이스

## 시작하기

### 설치

```bash
# 의존성 설치
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

http://localhost:3000에서 개발 서버를 확인하실 수 있습니다.

### 빌드

```bash
npm run build
npm start
```

## 디자인 컨셉

이 프로젝트는 다음과 같은 디자인 요소에 영감을 받았습니다:

- 유튜브의 애니메 J-POP 플레이리스트 썸네일
- 사카모토 데이즈 같은 일본 만화책 표지 디자인
- 애니메이션과 인터랙션이 풍부한 현대적인 웹 디자인

## 구조

```
devume-client2/
├── components/       # 리액트 컴포넌트
│   ├── home/         # 홈페이지 관련 컴포넌트
│   └── layout/       # 레이아웃 컴포넌트
├── pages/            # 페이지 컴포넌트
├── public/           # 정적 파일 (이미지 등)
├── services/         # API 및 서비스 레이어
├── server/           # 서버사이드 API 및 미들웨어
├── styles/           # 글로벌 스타일
└── utils/            # 유틸리티 함수
```
